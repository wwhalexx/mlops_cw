# Model card

## Назначение

Бинарная классификация токсичности русскоязычных комментариев с Pikabu/2ch.
Учебный HTTP-сервис; не автоматическая система наказаний или блокировок.

## Модель и происхождение artifact

Один sklearn Pipeline: `TextPreprocessor` → `TfidfVectorizer` → `LogisticRegression`.
Обучение выполняется с нуля на CPU. Выбор — максимум validation F1, затем average
precision; test не участвует. Все конфигурации и реальные run IDs находятся в
[отчёте](reports/experiments.json), краткая таблица — [здесь](reports/EXPERIMENTS.md).
Итоговые параметры и метрики публикуются вычислительным кодом, а не заполняются
ожидаемыми числами из прежнего ноутбука.

Artifact: [release_manifest.json](release_manifest.json) содержит URL, SHA-256 ZIP
и model version. Metadata модели содержит training commit, source checksum,
original MLflow run ID, data/split checksums и версии библиотек. Git tag фиксирует
код сервиса и ссылку на конкретную модель; training commit может быть его предком.
Версия API-ответа `sha256:...` вычисляется по реальному файлу `model.joblib`.
Скачивание модели и загрузка проверяют checksum. Не используйте чужие joblib:
десериализация pickle требует доверия источнику.

## Данные и оценка

[DATASET_CARD](DATASET_CARD.md). Одинаковый group-stratified split для всех шести
экспериментов: около 70/15/15. TF-IDF fit и классификатор обучаются только на train.
Порог 0.5 заранее зафиксирован. `class_weight=balanced`; score некалиброван.
Публикуются F1 положительного класса, precision, recall, accuracy, average precision
и ROC-AUC. AP — average precision, не трапецеидальная площадь PR-кривой.
Итоговые фактические значения и confusion matrix доступны в MLflow/экспорте.

## Ограничения

- От 15 очищенных до 10 000 входных символов; короткие оскорбления не поддерживаются.
- Модель не использует контекст треда, адресата, автора и историю сообщений.
- Возможны ошибки на цитатах, сарказме, политических темах, обсценной лексике без
  оскорбления, транслитерации, замаскированной ругани и непрямой агрессии.
- Данные могут содержать социальные смещения и ошибочную разметку. Чувствительные
  слова могут коррелировать с метками без причинной связи с токсичностью.
- Качество на отложенной части очищенного корпуса не доказывает качество на новых
  площадках. Нет независимого временного или межплатформенного тестирования.
- Не предназначена для медицинских, юридических решений, оценки личности,
  преследования людей или полностью автоматической модерации без пересмотра.
- Производительность зависит от длины текста и оборудования; строгий latency SLA
  не заявляется. API не сохраняет пользовательские тексты.

## Улучшения

Независимая проверка разметки, сбор контекста, внешний тестовый корпус,
калибровка score на отдельной выборке и контроль качества по подгруппам.
Эксперименты с BERT возможны как отдельная версия с новым artifact и оценкой ресурсов.
