# Изменения

## v1.0.1

- README: обычная установка пакета с `--no-editable`, запуск Streamlit через
  Python окружения, Docker PATH до первого запуска, явные порты и остановка старых процессов.
- UI: подсказка о длине; пустой и короткий текст проверяются до отправки HTTP
  с той же очисткой, что использует API. Серверная проверка сохранена.
- HTTP-клиент: русские сообщения для ошибок ввода, соединения, таймаутов,
  ограничений доступа/частоты, сбоев сервиса; внутренний JSON/HTML не показывается.
- Успешный ответ проверяется по общей с API схеме; некорректный ответ не ломает страницу.
- Автоматические тесты UI и ошибок HTTP-клиента; CI проверяет обычную установку
  и запускает реальную страницу через AppTest против собранного Docker API.
- Версия приложения — 1.0.1. Модель, параметры обучения, данные и model SHA-256
  остаются прежними. Повторное обучение для исправления интерфейса не требуется.

## v1.0.0

Первый релиз: подготовка двух версий данных, шесть MLflow экспериментов,
модельный artifact, FastAPI, Docker, тесты, CI, Streamlit и материалы сдачи.
